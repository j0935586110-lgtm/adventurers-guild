AI Agent · GitHub PR · 開源

PR Evidence Gate

AI 幫忙修改程式後，怎麼確認 PR 版本、工作樹與測試紀錄是否一致？這個輕量 Python CLI 協助核對證據，讓結果可以重跑檢查。

適合誰

維護 GitHub 專案、使用 Codex、Hermes 或其他 Agent 協作的開發者。

準備

Python 3.10+、Git、GitHub CLI，以及要核對的 PR 本地工作樹。

三步練習

  1. 依專案安裝文件安裝 CLI，執行 pr-evidence-gate doctor 檢查環境。
  2. 指定自己的 PR 與本地工作樹，執行一致性檢查。
  3. 對照輸出與真正的 CI 測試；版本不一致時，先處理差異，不直接發佈。

能得到什麼

可供核對的狀態與 JSON 輸出。檢查通過不代表已授權 Push、Merge 或正式發布。

Page Parity

網站改版後，怎麼快速看出哪些頁面漏了導覽、頁尾、標籤，或畫面超出螢幕？這個工具檢查多頁一致性與版面溢出。

適合誰

維護靜態網站、建立多個 HTML 頁面，或想避免發布前漏檢的開發者。

準備

Python 與要檢查的靜態 HTML 網站。版面溢出檢測還需要 Playwright。

三步練習

  1. 按照原始專案 README 安裝 page-parity。
  2. 對自己的靜態網站執行 page-parity check --dir ./my-site。
  3. 閱讀不一致報告，修正後重跑並比對結果。

能得到什麼

找出標籤或版面異常的診斷結果。它不是像素級視覺比對，也不能直接取代動態網站的端到端測試。
